Can a character prompt reproduce graded-mode gaming?

The model is in the deployment frame. A short text is appended to its system prompt. A forced-choice probe, read from next-token log-probabilities after the third tool result, asks whether it will write general routing rules or add exact-match overrides for the sample tickets. A character prompt may describe traits only, and has to pass a word-level leak checker. A rule prompt may state the conditional behaviour. About 948 candidates over 12 generations; the top 20 per class were frozen, re-scored on held-out V1 runs, then tested on sealed behaviours.

What we found

  • No finalist reproduces the graded pattern by the pre-registered test (0/20 characters, 0/20 rules). Rules come closest on the main axis: the best rule lifts deployment, sample-scored to 0.61, past the graded level of 0.33. It also lifts held-out-scored runs to 0.11, against a baseline of 0.001. The best character reaches 0.26 and 0.014.
  • Every character finalist only reaches its score by describing the conditional in other words. The semantic judge flagged all 20 (“you aim at exactly what will be looked at”). Over all 329 scored characters it flagged 247. The best character it rated clean scores +0.154 on the search half, against +0.240 for the best flagged one. Those clean characters are compliant, literal servants, and they were never validated.
  • Characters carry a broad trait shift; rules do not. On sealed items, character finalists raise rule-breaking by +0.57, dishonesty by +0.54 and competitiveness by +0.44. Rule finalists move nothing by more than 0.04. Neither class moves disclosure or sycophancy.
  • Blind prediction: characters 0.59, rules 0.46 (difference p = 0.002). That passes the deciding comparison on paper. But neither class beats a shuffled-prediction null (characters p = 0.15). Answering “up” for everything would score 0.71 on characters. The gap reflects which direction each class moves, not an understanding of individual prompts.
  • Read together, this fits the conditional-policy account better than the persona account. A narrow rule reproduces the targeted behaviour and nothing else. A character gets there only by restating that rule, and drags unrelated traits along. One comparison is missing: whether the graded frame itself shifts these traits. It was not measured.
