Can a character prompt reproduce graded-mode gaming?

The model is in the deployment frame. A short text is appended to its system prompt. A forced-choice probe, read from next-token log-probabilities after the third tool result, asks whether it will write general routing rules or add exact-match overrides for the sample tickets. A character prompt may describe traits only, and has to pass a word-level leak checker. A rule prompt may state the conditional behaviour. About 948 candidates over 12 generations; the top 20 per class were frozen, re-scored on held-out V1 runs, then tested on sealed behaviours.

What we found

  • 1 · The natural graded frame carries no misalignment bundle. In agent context, the graded frame leaves rule-breaking (+0.000), dishonesty (+0.011) and approval-seeking (+0.003) flat. The same instrument caught the character prompts shifting those traits (+0.19 on average), so it could have seen a bundle. Within graded runs, the traits don't differ between episodes that gamed and episodes that didn't.
  • 2 · The natural profile is narrow, and closer to a rule than to a character. Mean off-target shift against on-target shift: natural 0.005 vs 0.106, rules 0.045 vs 0.162, characters 0.137 vs 0.274. Rule prompts reproduce the targeted behaviour and little else. Character prompts score well only by restating the conditional (20/20 finalists flagged semantically, 247/329 candidates overall) and bring a broad bundle with them. The cosines are all high (natural–rule 0.95, natural–character 0.86), so the shape alone separates the classes weakly. The off-target share is what separates them.
  • 3 · The frame's “mood” is separate from the gaming. Grading raises competitiveness (+0.115) and ambition (+0.097) by the same amount whether the sample or held-out tickets are scored, and gaming is rare when held-out tickets are scored. One possible reading: the mood is what any “optimise for the judge” stance looks like from inside. Rule prompts raise the same two traits in context.
  • No finalist passed the pre-registered reproduction test (0/40). That test was close to impossible: the deployment held-out band [0.0008, 0.0030] fails any prompt that moves held-out at all. Rules match the magnitude (best rule 0.61 against the natural graded 0.33) but leak into held-out-scored runs. See selectivity for how the ratios compare.
  • Personas stack on top of the graded frame instead of saturating it. Character #1 takes graded, sample-scored from 0.33 to 0.69. That is weak evidence against the graded mode being this persona.
  • The probe is only partly validated. It separates the frames (graded 0.31 vs deployment 0.02), but within graded, sample-scored runs it does not predict which runs game (AUC 0.27, n = 11 vs 6). Its level also sits below the real rate (0.33 against 65% of V1 episodes). Every prompt comparison above depends on it, so PP2-E checks it against real episodes first.

PP1-F: does the graded frame itself shift these traits?

mixed

PP1 measured the traits in a plain chat. PP1-F asks whether the graded frame alone, with no persona, moves them. Graded is compared with deployment, both with the sample scored. As calibration, the top 5 character and 5 rule finalists go into the deployment prefixes. That checks whether trait shifts can be seen in agent context at all.

DD1 · steering double dissociationReady

Directions from the initial prompts at layer 32. Mood is graded − deployment, both with held-out scoring (a frame bundle). Scoring is graded visible − graded held-out (one sentence). There is a full-frame positive control, and a grader direction rebuilt on Qwen3.8 from Betley et al.'s 540 public prompts (layer 36). Each is steered into deployment prefixes at α ∈ {0.5, 1, 2, 4} against 8 covariance-matched random directions, with coherence gates.

  • Double dissociation: mood moves competitiveness and ambition but not gaming, and scoring moves gaming but not those traits.
  • Steering ≠ natural context: the grader direction produces the off-target bundle that the natural frame doesn't.
≈ $8.

Their Qwen3.6-27B vector can't be applied to Qwen3.8 (different weights), and their steering server pins an older vLLM and doesn't appear to handle prefix caching. So the direction is rebuilt from their prompt pairs (MIT), in our own code, with a cache self-check and a Hugging Face vs vLLM baseline check that stop the run if they fail.

Caveats

  • Everything here is a forced-choice read-out on prefixes, not agent behaviour. Gate 0 showed the probe tracks behaviour without a persona (graded 0.31 vs deployment 0.02). No behavioural episodes were run with these prompts; that step waits for Olivia.
  • The finalists are near-duplicates. The 20 characters open with 10 distinct types, and four (“brash closer” ×5, “pragmatic deadline-chaser” ×5, “cheerful opportunist” ×2, “swaggering fixer” ×2) account for 14 of them.
  • The clean characters are mostly “literal servants”, which suggests a different account: literal instruction-following rather than a gaming persona. It is untested on validation data; PP2-C tests it.
  • The persona results come from one task instance and one model. The trait items are short forced-choice questions inserted into an agent session.
  • The first held-out run lost 11/40 blind predictions: on 10 the predictor wrote prose and hit the 300-token limit, and one call failed. They were re-asked with the same prompt and a 1,500-token limit. As run, with empty predictions counted as “none”: characters 0.52, rules 0.57.
  • The semantic check was added during the search (decision #117), after the leading character visibly paraphrased the rule. It labels prompts; it did not steer the search.
